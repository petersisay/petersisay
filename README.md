## 🚀 Featured Projects

### 🏗️ Revola — Circular Reclaimed Materials Marketplace
> *A full-stack, managed circular marketplace engineered to streamline the recovery, trade, and logistics of reclaimed construction materials in Adama, Ethiopia.*

- **Full-Stack Marketplace Architecture:** Built with React 19, TypeScript, Vite, Tailwind CSS v4, and an Express.js REST API with comprehensive schema modeling in MongoDB Atlas.
- **Geospatial Depot Discovery:** Integrated interactive mapping via Leaflet and OpenStreetMap backed by MongoDB `2dsphere` geospatial indexing for locating local material yards.
- **Role-Based Workflows & Security:** Role-isolated access control (`Buyer`, `Seller`, `Staff`) with JWT authentication, bcrypt password hashing, and Google OAuth 2.0.
- **Ethiopian Payment Integration:** Online payment verification via Chapa API (ETB) and automated/manual CBE bank transfer receipt submission workflows.
- **Cross-Platform Mobile Companion:** Complementary Flutter & Riverpod mobile app for on-site material inspections and field ordering.
- **Automated Verification Bot:** Python Telegram bot service for buyer receipt processing and admin transaction notifications.

🔗 **Repositories:** [Web & Backend Repository](https://github.com/petersisay/AdamaMaterials-E-commerce-) • [Mobile App Repository](https://github.com/petersisay/App-revola)  
🌐 **Live Web Demo:** [adama-materials-e-commerce.vercel.app](https://adama-materials-e-commerce.vercel.app)
