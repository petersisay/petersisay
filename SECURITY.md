# Security Policy

## Supported Versions

As this repository hosts the GitHub profile configuration, documentation, and automation workflows for [@petersisay](https://github.com/petersisay), only the current default branch is actively maintained.

| Version / Branch | Supported          |
| ---------------- | ------------------ |
| `main`           | :white_check_mark: |
| Older revisions  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or potential risk within this repository or associated profile workflows, please report it privately.

### Security Contact
Please email details to:
- **Email:** [petrossisay1646@gmail.com](mailto:petrossisay1646@gmail.com)

### What to Include
To help evaluate and address the issue efficiently, please include:
- A clear description of the vulnerability.
- Steps to reproduce or a proof of concept demonstrating the issue.
- The potential impact of the vulnerability.
- Any suggested remediations or mitigations.

### Responsible Disclosure
- Please do not disclose vulnerabilities publicly or report them via public GitHub issues prior to coordinated review.
- Reports will be reviewed as promptly as feasible, and updates will be communicated directly via email.
